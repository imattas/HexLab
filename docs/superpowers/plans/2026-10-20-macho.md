# Mach-O Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans inline. One fresh whole-stage reviewer at completion; no implementer/per-task agents. Standing user authorization replaces approval pauses.

**Goal:** Original Mach-O thin/universal loading, static facts and real persistent CLI/wx workflows in the existing shared DLL suite.

**Architecture:** Checked container envelopes feed bounded format parsers and typed metadata. Image mappings, reference provenance, source binding and workers remain authoritative across consumers.

**Tech Stack:** C++20, CMake, existing shared engines, SQLite and wxWidgets; observed LLVM only for tests.

**Spec:** docs/superpowers/specs/2026-10-20-macho-design.md

## Global constraints

- Original parser; no production dependency or execution of inputs. Preserve all existing enum ordinals/recipe bytes/user history and accepted installation prefixes.
-4096 slices,65536 commands per slice,1048576 aggregate commands;64MiB combined command/descriptor and parsed-metadata budget. Headers28/32, FAT descriptors20/32, command envelope8; command alignment4/8.
- All exposed file offsets are absolute outer-container coordinates, checked within selected slice. Whole-container storage/export and explicit persistent slice identity.
- No GUI I/O/SQL/decode/full-table scans; bounded cancellable worker parsing. Unknown contexts/relationships remain explicit.
- Preserve unborn feat/foundation/index; no commits/destructive cleanup/approval prompts. Full consumer rebuild for layout changes; no source mutation during dependent builds/tests. Debug/Release sequential per tree.
- New MachODebug install only. Completing this plan leaves the full IDA-class goal active.

## Review focus

1. A fat slice whose inner table fits the outer file but crosses its slice must fail (tasks1/2/3).
2. Object sections with equal raw addresses and nonzero section.addr must keep distinct symbols/annotations and correct offsets (tasks2/3/5/6).
3. __PAGEZERO, SG_HIGHVM, zero-fill and compatible/conflicting overlaps must not fabricate backing (task2).
4. Retained linked relocations, paired/subtractor and dyld fixups must not reapply linked bytes or seed false callees (task4).
5. Patching selection headers, names or dyld payloads must invalidate facts while preserving unselected slices, embedded source/history and stale-worker rejection (tasks5/6).

# AArch64 bitfield scalar support

## Goal

Extend the original AArch64 decode-to-lift path with the commonly used `UBFM` and `SBFM` bitfield operations, including their `LSL`, `LSR`, `UBFX`, `ASR`, and `SBFX` aliases. Preserve fixed-width decoding, register width and XZR behavior, and leave unsupported `BFM` explicit.

## Steps

1. [x] Add failing decoder tests for 32/64-bit UBFM/SBFM encodings, aliases, malformed immediates, and exact operand/effect/format metadata.
2. [x] Add failing decompiler tests using decoded instructions for logical extraction, sign extraction, aliases, SSA, and XZR discarded writes.
3. [x] Implement typed opcodes, bounded decode, alias formatting, and deterministic bitfield extraction/extension lifting.
4. [x] Document exact supported behavior and limitations in `docs/a64-bitfield.md`.
5. [x] Build and run focused A64 decoder and decompiler tests in an isolated build directory, plus `git diff --check`.

## Limits

This task does not implement `BFM`/`BFC`/`BFXIL`, condition-select, SIMD/FP, system instructions, or whole-function AArch64 semantic coverage. Rotates in the IR expression remain explicit compositions rather than a dedicated rotate primitive.

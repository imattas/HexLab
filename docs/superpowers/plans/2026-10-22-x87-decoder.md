# x87 Decoder Milestone Plan

> **For agentic workers:** Implement this milestone test-first in the shared custom x86 decoder. Keep persisted enum values stable and use an isolated build directory.

**Goal:** Decode the architecturally common x87 instruction forms in D8–DF across x86-16, x86-32, and x86-64, with typed register/memory operands, explicit x87 stack accesses, exact effective memory widths, and bounded invalid/truncated behavior.

**Architecture:** Add an x87 register bank and one appended generic x87 opcode whose exact mnemonic is retained in the instruction. Decode D8–DF ModRM forms in the existing mode-aware decoder and reuse its address parser, including segment/address-size behavior. Model explicit operands using the existing typed `RegisterOperand` and `MemoryOperand`; capture stack-register reads/writes explicitly. Unsupported/reserved subencodings fail closed as invalid where reservedness is determined from the encoding, and unsupported where the form is valid but intentionally unimplemented.

**Tech Stack:** C++20, existing `libs/processors`, test executables `x86_16_decoder_tests` and `x86_32_decoder_tests`.

## Test-first sequence

1. [x] Add tests for x87 register names and canonical formatting, representative arithmetic/compare/load/store/pop forms, implicit x87 stack effects, memory widths (16/32/64/80 and environment/state forms), and address-size/segment parsing across modes.
2. [x] Add fail-closed tests for invalid reserved ModRM subencodings, every truncation of representative ModRM/SIB/displacement forms, and the architectural 15-byte instruction limit.
3. [x] Append opcode/register-bank values without shifting persisted values, implement the D8–DF decoder, typed memory/register effects, and formatting.
4. [x] Run focused tests in an isolated CMake build; `hexlab_x86_16_decoder_tests` and `hexlab_x86_32_decoder_tests` pass in `.agent-x87-build`.
5. [x] Document covered opcode groups and explicit unsupported boundaries in `docs/x87-decoder-coverage.md`.

## Scope boundary

Prioritize the common numeric stack, load/store, arithmetic, compare, control-word/environment, constants, and transcendental forms. Reserved encodings must be rejected exactly for implemented groups. Valid but unimplemented groups remain explicit `unsupported`; this milestone does not claim complete x87/MMX/SSE coverage, execution semantics, or full floating-point flag modeling.

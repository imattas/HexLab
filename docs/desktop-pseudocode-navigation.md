# Pseudocode origin navigation

Selecting a pseudocode source line that carries an instruction origin moves the active document selection to that address. The disassembly listing selects and reveals the matching instruction; the CFG canvas selects the containing block, highlights the instruction row when available, and pans it into view. The same reveal action runs when the selected origin is already the workspace selection. When a graph is being rebuilt, its canvas retains the reveal request and applies it when a current graph becomes available.

Origin navigation carries the document ID and workspace document revision used to render the pseudocode, plus the project UUID and edit/byte/decision revisions. The main frame checks those values against the active workspace and current project before moving the shared selection. A closed, replaced, inactive, or revised document cancels the navigation and reports that the origin is stale. Pseudocode generated from an untitled workspace uses the workspace document ID/revision guard without project revisions.

Navigation is address-backed only: pseudocode rows without a validated instruction-origin annotation do not move the listing or graph. The CFG can reveal only addresses represented by its current graph; missing nodes remain selected as workspace locations and are revealed if a later graph contains them.

Stack-local renames and type assignments apply to every recovered access site for that slot in one project command. Unique register SSA variables also collect their defining instruction and all instructions that read that exact version, including register inputs, memory base/index operands, and nested expressions. Renames and type assignments apply to those sites atomically. The underlying name annotations and type assignments remain address-keyed, so existing project files and history can replay the edits without a schema change. Each command accepts at most 4,096 distinct access sites; larger variables remain visible but read-only. Undo and redo restore the complete edit as one history step. Phi-only SSA values remain read-only because current address-keyed records cannot distinguish them from other values or instruction annotations at the block entry.

Use **Ctrl+F** while the pseudocode pane is focused to search the currently rendered function. Search is a literal, case-sensitive match, wraps at either end, and selects/reveals each result; Enter and the Previous/Next buttons move between matches, while Shift+Enter moves backward. **Escape** returns focus to the pseudocode. The query is limited to 256 characters and the scan to the first 1 MiB of rendered text. Selecting a result with a mapped instruction origin follows the normal document/project revision guard, so a stale render cannot navigate the active workspace. Search only reads the rendered pseudocode and does not change project state.
